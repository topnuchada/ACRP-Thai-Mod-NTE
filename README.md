# NTE[JP] — ACRP Thai Localization Project

> ม็อดภาษาไทยแบบไม่เป็นทางการสำหรับ **Neverness to Everness (NTE)**  
> พัฒนาจาก **ช่องภาษาญี่ปุ่น (JP)** โดยเน้นถ่ายทอดสำนวน น้ำเสียง และอารมณ์ของบทญี่ปุ่นให้เป็นภาษาไทยที่อ่านเป็นธรรมชาติ

---

## เกี่ยวกับโปรเจกต์

**NTE[JP]** เป็นโปรเจกต์ Fan-made Thai Localization ที่จัดทำขึ้นจากความชอบส่วนตัว เพื่อให้ผู้เล่นที่ใช้เสียงพากย์ภาษาญี่ปุ่นสามารถติดตามเนื้อเรื่อง บทสนทนา และรายละเอียดต่าง ๆ ของเกมเป็นภาษาไทยได้ง่ายขึ้น

แนวทางการแปลไม่ได้เน้นการแปลตรงคำทุกประโยค แต่พยายามรักษา **ความหมาย เจตนา บุคลิก น้ำเสียง และอารมณ์ของตัวละครจากภาษาญี่ปุ่น** ให้มากที่สุด

โปรเจกต์นี้ทำในเวลาว่างและไม่ได้จัดทำในเชิงพาณิชย์

**ความตั้งใจคือจะพัฒนาและอัปเดตต่อไปเรื่อย ๆ จนกว่า NTE จะมีภาษาไทย Official**

## จุดเด่นของ NTE[JP]

- แปลจากบริบทและสำนวนภาษาญี่ปุ่น
- พยายามรักษาบุคลิกและน้ำเสียงของตัวละคร
- ใช้ช่องภาษา JP เป็นฐาน
- เน้นเฉพาะภาษาและการแสดงผลภาษาไทย
- ไม่ได้มีจุดประสงค์เพื่อปรับ Damage, Stat, Gacha หรือ Gameplay
- สามารถอยู่แยกจากม็อดภาษาไทยที่ใช้อีกช่องภาษาได้

## วิธีใช้งาน

NTE[JP] ใช้ **ช่องภาษาญี่ปุ่นของเกมเป็นฐาน**

ก่อนใช้งาน ผู้เล่นจะต้องตั้งค่าภาษาในเกมเป็น **ภาษาญี่ปุ่น** เพื่อให้ตัวเกมเรียกใช้ข้อความจากช่องภาษาที่ม็อดปรับไว้

> คู่มือการติดตั้งฉบับเต็มและไฟล์ Release จะเพิ่มในหน้านี้เมื่อเวอร์ชันสำหรับใช้งานจริงพร้อมปล่อย

## ⚠️ คำเตือนเรื่องความเสี่ยง

Neverness to Everness เป็นเกมออนไลน์ และการใช้งานม็อดมีการปรับเปลี่ยนไฟล์บางส่วนของเกม

ผู้จัดทำ **ไม่สามารถรับรองได้ว่าการใช้งานจะปลอดภัยจากการตรวจจับ การเตือน การระงับบัญชี หรือการลงโทษจากผู้ให้บริการเกม 100%**

ผู้ใช้งานควรศึกษาข้อมูลและยอมรับความเสี่ยงด้วยตนเองก่อนติดตั้ง

โปรเจกต์นี้ไม่เกี่ยวข้องกับระบบโกง และไม่ได้มีจุดประสงค์เพื่อแก้ไข:

- Damage / Stat / Cooldown
- Gacha / Currency / Reward
- ระบบ Gameplay
- Network หรือ Server Data
- Anti-cheat
- Bot / Macro / Automation

## การนำไปใช้ / Usage Policy

**NTE[JP] / ACRP Thai Localization Project** จัดทำขึ้นเพื่อการใช้งานส่วนบุคคลและไม่แสวงหากำไร

สามารถนำม็อดไปใช้ประกอบคลิป YouTube, Facebook, TikTok, Live Stream หรือคอนเทนต์อื่น ๆ รวมถึงคอนเทนต์ที่มีรายได้ได้ โดยขอความร่วมมือให้ระบุเครดิต **NTE[JP] / ACRP Thai Localization Project** และแนบลิงก์กลับมายัง GitHub ต้นทางของโปรเจกต์เมื่อสามารถทำได้

### อนุญาต

- ใช้งานม็อดเพื่อเล่นเกมส่วนบุคคล
- ใช้ม็อดในคลิป วิดีโอ รีวิว หรือ Live Stream
- สร้างรายได้จากคอนเทนต์ที่ผู้สร้างทำขึ้นเอง โดยให้เครดิตโปรเจกต์และลิงก์กลับต้นทาง

### ไม่อนุญาตโดยไม่ได้รับอนุญาตจากผู้จัดทำ

- นำไฟล์ม็อดหรือผลงานแปลไปจำหน่าย
- นำตัวม็อดไปรวมไว้ในบริการ แพ็กเกจ หรือระบบแบบเสียเงิน
- รีแพ็ก เปลี่ยนชื่อ หรืออ้างว่าเป็นผลงานของตนเอง
- รีอัปโหลดไฟล์ม็อดไปแจกจากแหล่งอื่นแทน GitHub ต้นทาง
- นำผลงานแปลไปใช้ในเชิงพาณิชย์โดยไม่ได้รับอนุญาต

หากต้องการแชร์ม็อด กรุณาแชร์ลิงก์จาก **GitHub ต้นทางของโปรเจกต์** เพื่อให้ผู้ใช้งานได้รับไฟล์เวอร์ชันล่าสุดและข้อมูลจากผู้จัดทำโดยตรง

หากต้องการนำตัวม็อดหรือผลงานแปลไปใช้ในเชิงพาณิชย์ กรุณาติดต่อเพื่อขออนุญาตก่อน
