# ACRP-Thai-Mod-NTE

ม็อดภาษาไทยแบบไม่เป็นทางการสำหรับ Neverness to Everness โดย ACRP แปลจากภาษาญี่ปุ่นในเกม

## การนำไปใช้ / Usage Policy

**NTE[JP] / ACRP Thai Localization Project** จัดทำขึ้นเพื่อการใช้งานส่วนบุคคลและไม่แสวงหากำไร

สามารถนำม็อดไปใช้ประกอบคลิป YouTube, Facebook, TikTok, Live Stream หรือคอนเทนต์อื่น ๆ รวมถึงคอนเทนต์ที่มีรายได้ได้ โดยขอความร่วมมือให้ระบุเครดิต **NTE[JP] / ACRP Thai Localization Project** และแนบลิงก์กลับมายัง GitHub ต้นทางของโปรเจกต์เมื่อสามารถทำได้

### อนุญาต
- ใช้งานม็อดเพื่อเล่นเกมส่วนบุคคล
- ใช้ม็อดในคลิป วิดีโอ รีวิว หรือ Live Stream
- สร้างรายได้จากคอนเทนต์ที่ผู้สร้างทำขึ้นเอง โดยให้เครดิตโปรเจกต์และลิงก์กลับต้นทาง

### ไม่อนุญาตโดยไม่ได้รับอนุญาตจากผู้จัดทำ
- นำไฟล์ม็อดหรือผลงานแปลไปจำหน่าย
- นำตัวม็อดไปรวมไว้ในบริการ แพ็กเกจ หรือระบบแบบเสียเงิน
- รีแพ็ก เปลี่ยนชื่อ หรืออ้างว่าเป็นผลงานของตนเอง
- รีอัปโหลดไฟล์ม็อดไปแจกจากแหล่งอื่นแทน GitHub ต้นทาง
- นำผลงานแปลไปใช้ในเชิงพาณิชย์โดยไม่ได้รับอนุญาต

หากต้องการแชร์ม็อด กรุณาแชร์ลิงก์จาก **GitHub ต้นทางของโปรเจกต์** เพื่อให้ผู้ใช้งานได้รับไฟล์เวอร์ชันล่าสุดและข้อมูลจากผู้จัดทำโดยตรง

หากต้องการนำตัวม็อดหรือผลงานแปลไปใช้ในเชิงพาณิชย์ กรุณาติดต่อเพื่อขออนุญาตก่อน

> เงื่อนไขข้างต้นใช้กับผลงานแปลและไฟล์ที่จัดทำขึ้นโดย ACRP Thai Localization Project เท่านั้น โปรเจกต์นี้ไม่ได้อ้างสิทธิ์ในตัวเกม ทรัพย์สิน เครื่องหมายการค้า หรือเนื้อหาต้นฉบับของ Neverness to Everness
