## วิธีติดตั้ง MOD ภาษาไทย NTE

1. แตกไฟล์ ZIP / RAR ที่ดาวน์โหลดมา
2. Copy โฟลเดอร์ **`HT`**
3. นำโฟลเดอร์ **`HT`** ไปวางที่โฟลเดอร์ติดตั้งเกม:

```text
...\Neverness To Everness [Folder ที่ติดตั้งเกม]\Client\WindowsNoEditor\
```

4. หาก Windows ถามเรื่องไฟล์หรือโฟลเดอร์ซ้ำ ให้เลือก **Merge / Replace** และก๊อปทับลงไป  
   **อย่าลบไฟล์หรือโฟลเดอร์ของเกมเดิมออก**
5. เปิดเกมตามปกติ
6. ตั้ง **ภาษาข้อความในเกมเป็นภาษาญี่ปุ่น**  
   แนะนำให้ใช้ควบคู่กับ **เสียงพากย์ญี่ปุ่น**

### วิธีถอน MOD

เข้าไปที่:

```text
...\Client\WindowsNoEditor\HT\Content\Paks\
```

แล้วลบเฉพาะไฟล์ต่อไปนี้:

```text
pakchunk3001-Windows_3001_P.pak
pakchunk3001-Windows_3001_P.ucas
pakchunk3001-Windows_3001_P.utoc
```
- ลบอีก 2 ไฟล์คือ NTESigBypasser.asi  และ  winhttp.dll  ที่อยู่ใน \HT\Binaries\Win64  ลบได้ ในกรณีที่ไม่ต้องการใช้ MOD จากที่อื่นๆด้วย ถ้ายังอยากใช้MOD ของที่อื่นต่อไม่ต้องลบ2 ไฟล์นี้ออก

> ⚠️ **ห้ามลบโฟลเดอร์ `HT` ทั้งก้อน**

## ⚠️ คำเตือนเรื่องความเสี่ยง

Neverness to Everness เป็นเกมออนไลน์ และการใช้งานม็อดมีการปรับเปลี่ยนไฟล์บางส่วนของเกม

ผู้จัดทำ **ไม่สามารถรับรองได้ว่าการใช้งานจะปลอดภัยจากการตรวจจับ การเตือน การระงับบัญชี หรือการลงโทษจากผู้ให้บริการเกม 100%**

ผู้ใช้งานควรศึกษาข้อมูลและยอมรับความเสี่ยงด้วยตนเองก่อนติดตั้ง

โปรเจกต์นี้ไม่เกี่ยวข้องกับระบบโกง และไม่ได้มีจุดประสงค์เพื่อแก้ไข:

- Damage / Stat / Cooldown
- Gacha / Currency / Reward
- ระบบ Gameplay
- Network หรือ Server Data
- Anti-cheat
- Bot / Macro / Automation

## การนำไปใช้ / Usage Policy

**NTE[JP] / ACRP Thai Localization Project** จัดทำขึ้นเพื่อการใช้งานส่วนบุคคล ตัวม็อดแจกฟรี และไม่อนุญาตให้นำไฟล์ไปขายต่อ

สามารถนำม็อดไปใช้ประกอบคลิป YouTube, Facebook, TikTok, Live Stream หรือคอนเทนต์อื่น ๆ รวมถึงคอนเทนต์ที่มีรายได้ได้ โดยขอความร่วมมือให้ระบุเครดิต **NTE[JP] / ACRP Thai Localization Project** และแนบลิงก์กลับมายัง GitHub ต้นทางของโปรเจกต์เมื่อสามารถทำได้

### อนุญาต

- ใช้งานม็อดเพื่อเล่นเกมส่วนบุคคล
- ใช้ม็อดในคลิป วิดีโอ รีวิว หรือ Live Stream
- สร้างรายได้จากคอนเทนต์ที่ผู้สร้างทำขึ้นเอง โดยให้เครดิตโปรเจกต์และลิงก์กลับต้นทาง

### ไม่อนุญาตโดยไม่ได้รับอนุญาตจากผู้จัดทำ

- นำไฟล์ม็อดหรือผลงานแปลไปจำหน่าย
- นำตัวม็อดไปรวมไว้ในบริการ แพ็กเกจ หรือระบบแบบเสียเงิน
- รีแพ็ก เปลี่ยนชื่อ หรืออ้างว่าเป็นผลงานของตนเอง
- รีอัปโหลดไฟล์ม็อดไปแจกจากแหล่งอื่นแทน GitHub ต้นทาง
- นำผลงานแปลไปใช้ในเชิงพาณิชย์โดยไม่ได้รับอนุญาต

หากต้องการแชร์ม็อด กรุณาแชร์ลิงก์จาก **GitHub ต้นทางของโปรเจกต์** เพื่อให้ผู้ใช้งานได้รับไฟล์เวอร์ชันล่าสุดและข้อมูลจากผู้จัดทำโดยตรง
